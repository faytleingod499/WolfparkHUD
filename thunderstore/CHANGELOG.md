## 1.16.3
- The command list is in alphabetical order.
- Clicking a command sends it to the server right away, no typing. Commands that need more (a player, an amount, a
  name...) open a small box under them with a hint of what to type; press Enter or Send.
- Commands that affect everyone (exit, clearchalk, clearoutside, reloadplugins, ban, say) are red and need a second
  click.

## 1.16.2
- The command list is more compact: a smaller font, at most a few rows tall (less near the bottom of the screen) with
  a scrollbar, and every command is a button you can click to type it in chat.

## 1.16.1
- New **?** button left of the title (next to the admin shield for admins): a list of every command you can use on
  the server, with what it does. Click a command to have it typed in chat for you.
- It asks the server with !help in the background and shows the answer in the list instead of in chat, so it works
  without any server update.

## 1.15.0
- New **Chalk** button: a menu for your chalk saves. Pick a canvas (it starts on the nearest one), type a name and
  **Save**, or **Load**, **Share** or **Delete** any of your saves. Loading, deleting and saving over a save ask for a
  second click. When someone shares a save with you, **Accept** and **Decline** show up in the menu.
- Admins get an **All players** list in the Chalk menu: everyone who has saves, online or not. Click a name to see
  their drawings and load or delete them.
- Needs the updated Chalk Saves plugin on the server.
